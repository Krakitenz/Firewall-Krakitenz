# Firewall-Krakitenz

Экспериментальный Windows firewall на C++ с использованием Windows Filtering Platform (WFP).

## Статус

Проект находится на стадии раннего прототипа (`v0.1.0-alpha`).

Сейчас реализовано:

- структурированное ядро проекта;
- собственный WFP engine и sublayer;
- добавление и удаление WFP-фильтров;
- блокировка исходящих TCP-соединений по удалённому порту;
- управление правилами через `FirewallRule` и `RuleManager`;
- мониторинг активных TCP-соединений;
- автоматическая очистка созданных правил при завершении.

## Ограничения

- поддерживаются только исходящие TCP-правила по порту;
- правила пока хранятся только в памяти;
- для работы с WFP требуются права администратора;
- графического интерфейса пока нет;
- проект не заменяет системный firewall и не предназначен для production-использования.

## Структура

```text
src/
├── App/       # Точка входа и консольное меню
├── Core/      # Модель правил и управление ими
├── Network/   # Мониторинг сетевых соединений
└── Platform/  # Windows Filtering Platform backend
```

## Сборка

1. Открыть `Firewall.vcxproj` в Visual Studio.
2. Выбрать конфигурацию `Debug` или `Release` и платформу `x64`.
3. Собрать проект.
4. Запускать приложение от имени администратора для операций WFP.

## Предупреждение

Это учебный проект. Перед использованием проверяйте созданные фильтры и не запускайте экспериментальные правила на критически важной системе.
